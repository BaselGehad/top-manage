# Top Manage

**Top Manage** is a small program of offline browser tools for piping test-pack work.
**Top Manage** برنامج صغير فيه أدوات بتشتغل أوفلاين على المتصفح لشغل التست باك في البايبينج.

Open `index.html` to see the home page with both tools. / افتح `index.html` هتلاقي الصفحة الرئيسية بالأداتين.

## Tools / الأدوات

### 1. Selection Set builder: `TP_selectionset_tool.html`
Converts an Excel line list (columns `Line No` and `Testpack No`) into a Navisworks selection-set XML, one selection set per test pack.
بتحوّل شيت إكسل (عمودين: `Line No` و `Testpack No`) لملف XML لـ Navisworks فيه selection set لكل تست باك.

### 2. Test Pack Monitor: `TP_monitor_tool_no_index.html`
Builds a test-pack monitor workbook from spool dump and weld dump files, using a circuit-to-ISO index file that you load yourself.
بتعمل شيت متابعة للتست باك من ملفات Spool Dump و Weld Dump، وبتحتاج ملف فهرس الدوائر (Circuit to ISO) اللي انت بتحمّله.

## How to use / الاستخدام

1. Download the repo files, or open the GitHub Pages site if it is enabled.
2. Open `index.html` in Chrome or Edge and pick a tool. No install, no internet needed.
3. Drag your Excel files into the tool.

حمّل الملفات وافتح `index.html` في كروم أو إيدج، واختار الأداة، واسحب ملفات الإكسل جواها. مفيش تثبيت ولا نت.

## Privacy / الخصوصية

Everything runs inside your browser on your own device. No file or data is uploaded anywhere. This repository contains only the tools, no project data.
كل حاجة بتشتغل جوه المتصفح على جهازك، ومفيش أي ملف بيتبعت لأي مكان. الريبو فيه الأدوات بس، من غير أي داتا مشروع.
